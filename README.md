# Private Motors

A responsive owner-to-buyer car marketplace demo. No dealerships.

Includes mock vehicle listings, search and filters, saved cars, vehicle details, owner contact previews, and seller listing previews. Demo forms do not send or store information. Favorites remain in memory for the current page session.

## Host on GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then click **Save**.
4. Once GitHub finishes deploying, visit https://ritanshu0001.github.io/PrivateMotors/.

No build step or dependencies are needed. All asset links are relative, so the site works under the repository URL.

## Local preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Assets

Car photographs are illustrative images from Unsplash. Owners, prices, specifications, and descriptions are fictional. Google Fonts supplies DM Sans and Manrope. An internet connection is needed for these external assets.
